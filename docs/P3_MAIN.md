## 计时器

标题“我们已经认识了”。精确起点：`2026-10-09T08:15:00+08:00`。显示 `N天 HH小时 MM分钟 SS秒`，最大强调天数，另外三组2位。每秒真实计算，不假设每次浏览器 `setInterval` 都准时。

```js
const startMs = new Date('2026-10-09T08:15:00+08:00').getTime();
function timeParts(now=Date.now()) {
  const n = Math.max(0, Math.floor((now-startMs)/1000));
  return {
    days: Math.floor(n/86400),
    hours: String(Math.floor(n%86400/3600)).padStart(2, '0'),
    minutes: String(Math.floor(n%3600/60)).padStart(2,'0'),
    seconds: String(n%60).padStart(2,'0')
  };
}
```

初次渲染立即填真实值；切回 P3/切回浏览器前台 `visibilitychange` 立即更新，闰日和跨时区通过 epoch差自动正确。下方写“开始记录：2026.10.09 08:15（北京时间）”。

## 点击角色

小杨随机4句，团子随机3句，**保持用户原文**，都从 `content/P3_CONTENT.json` 读取。每次点击显示 ~2.5–3.5s气泡，更新文字可重新计时；优先别连续一样。猫独立点击区不能被人物罩住，点击左侧小杨不能误点团子。诡秘无需随机台词，不要自行写。

## 三分叉入口

今日运势 / 时间胶囊 / 应急按钮。CSS/SVG做三枚有趣的猫系星星吊坠或星星+标签的按钮：可微摇，标签放在真实DOM，点按 44px+。用户提及“吊坠、星星”的设计意象；具体排版由Codex决定。点击 P4 对应分页面；离开 P3 不丢失计时基准，返回无需重走密码页。

## 背景与移动布局

用户批准的是一张暖色猫系室内背景，已有猫耳钟、书架和猫爪地毯。不要再重画窗/猫钟，不要把正文压在强光窗户或家具上。九比十六手机显示完整，短屏可轻微滚动；功能入口必须可点，计时数字不能被人像覆盖。
