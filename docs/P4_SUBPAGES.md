# P4 三分页面｜开发约束

## 共用

可以用一个 P4 模板渲染3种状态，但不拆成3个 GitHub Pages 子路由。背景共用 `./assets/p3/P3_BG_01.webp`，可加不透明的奶油色遮罩减低干扰。**三个分页面始终要有 `返回主页` 实体按钮**；点击回 `p3_home`，不能回 P1/P2。

## A：今日运势（可用功能）

- 主素材：`./assets/p4/P4_FORTUNE_MACHINE_01.png`，透明像素猫爪星光扭蛋机。不得重画成其他机器。
- 标题：`团子今日运势`。
- 抽签前机器居中，按钮 `抽一签`；点击后机器轻摇（整张PNG，并非独立摇杆）、约 0.5–1s 后显示结果签文卡。抽签后机器可以缩小，卡片必须完整可读。
- 数据：`content/P4_FORTUNE_CONTENT.json`，**恰好10条用户最终选的签文**。每签 `id/title/grade/description/good/avoid/tag` 原样显示。JSON不可擅改原句或新增签文。
- 首次抽时 10条等概率；重抽时排除上次一条，其余9条等概率，避免连续重复；可无限抽，不按日期限制。统计意义上长期每条出现公平。
- 结果卡包含：签名/等级/标签、正文、今日宜/今日忌和 `再抽一签`；不要用 `alert`。底部小字 `娱乐抽签，仅供开心。`，不要包装成真实预测。
- 长句折行与舒适字号必须保证，内容多时页面应自然纵向滚动。

## B：时间胶囊（未开放）

标题：`时间胶囊`；文案：`时间胶囊正在施工中，挖到回忆就通知你！`；共用 `./assets/p4/P4_DEV_01.png`（戴黄色安全帽小杨、头顶团子猫、拿镐），配明确 `开发中` 字样，不用造完整时间胶囊逻辑。

## C：应急按钮（未开放）

标题：`应急按钮`；文案：`应急通道正在抢修中，小杨施工队已经到达现场！`；共用 `./assets/p4/P4_DEV_01.png`，配明确 `开发中` 字样，不用伪装成实际帮助功能。

## 注意

三个子页都能滚动、能返回；签文不要复制旧项目文案；无支付、账号、后台、登录、外链等额外需求。
