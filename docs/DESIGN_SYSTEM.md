# 视觉体系｜像素猫系时间小屋

**内核是小杨和诡秘相识时间记录。可爱像素、猫咪、星星只是画风。**

- 配色基调：奶油白 `#FFF7E9` / 米黄 `#F9E6C4` / 浅金 `#F6D98E` / 暖木色 `#B77D58` / 深棕字体 `#674B42` / 浅鼠尾草绿 `#9BAB83`。允许从图片本身采样微调，不能突然切为深色赛博紫。
- 正文中文优先系统无衬线（`-apple-system, BlinkMacSystemFont, 'Microsoft Yahei', sans-serif`），标题可局部用像素字体或粗体，但不为可爱牺牲可读性。不从外部 CDN 强制加载字体。
- UI：浅奶油色实体卡、1–3px 棕色描边、轻阴影、方圆兼容的像素味倒角；请不要全屏毛玻璃大渐变。按钮触摸 44px 起。计时器数值要居全站首位，使用 tabular-nums。
- 角色形象已经选定；Q版像素人物比 P3 背景像素块更粗，这是可接受的。保持 PNG 透明和比例，别套 blur/AI 粒子。
- P3 背景有窗光、猫钟、猫爪墙饰、书架、地毯；避免重复再盖很多装饰。背景中央原本留白，要用来承载 UI。
- P3三功能入口：可用3枚统一星星吊坠 + 下方中文小木牌，或小星/胶囊/心的区分性图标；优先统一、可点、可读。建议 pendants 轻摇 `transform-origin: top center`，禁纯装饰 inert 按钮。
- 加载: CSS 像素进度条，少量静态像素星星，Q版四帧原始绘制保持平滑，不强制 `image-rendering:pixelated`。
- 动画要轻且低频：按钮按下轻缩小，猫轻 bounce，气泡渐入渐出，门在正确后开；避免无意义眩光和密集粒子。
- 开发中页面可用施工 Q版 + 手绘木牌风标题 + 返回主页。今日运势用签卡标题/签级/标签/文案/宜忌层次分明。长句必须自动换行。
- 参考 P1完整设计图把握氛围，不要求把所有画死文字恢复进原位置；参考 P3线框图把握秩序，**绝对不要沿用其简笔人像、纯色盒子当最终美术**。
