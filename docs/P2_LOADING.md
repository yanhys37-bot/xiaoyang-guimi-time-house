# P2 加载过渡｜开发约束

四张透明 PNG 在 `assets/p2`。精确顺序 `P2_CH_F01`（1000095819，正常看书）→`F02`（1000095820，团子眨眼）→`F03`（1000095822，开心）→`F04`（1000095821，眯眼微笑）。这不是按用户当次图片上传先后排序。

总时长 2400ms，逐帧 300ms，四帧循环两轮。帧位图使用同一个768×768容器，每次替换 src；图片保持统一宽高/位置，不让透明留白变化引起整个 DOM 大幅跳动。预载帧以防闪烁。

文案：0–800ms `正在打开时间小屋……`；800–1600ms `正在翻找我们的相识记录……`；1600–2400ms `找到啦，准备进入！`。顶部 `小杨 × 诡秘 · 时间小屋`。暖奶油底，CSS/SVG 小星与像素进度条 0→100%。

2.4秒结束进入 `p3_home`，不要改 URL Path；确保下一屏主要背景加载就绪。不是网络真实下载进度，避免等待无限久。离开 P2 清理 `setInterval`/`setTimeout`，`prefers-reduced-motion` 则静帧与简短过渡。过场始于 P1 正确，手机输入键盘应收起。
