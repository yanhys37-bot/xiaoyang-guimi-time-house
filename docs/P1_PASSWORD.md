## 文案（来自 content/P1_CONTENT.json）

主标题“小杨 × 诡秘”，副标题“时间小屋入口”，小英文“TIME RECORD”，输入引导“请输入六位暗号”，按钮“开门啦！”，底部“嘘，这是一个藏着时间的小地方。”；如果布局空间紧张，英文/底部小字可以隐藏，但主标题、输入区、按钮必须保留。

### 密码响应

- 空输入：`还没输入暗号呢，喵～`
- 少于6位：`咦？暗号还差N位哦。`（动态 N）
- 6位但错误，第1次：`喵？这串暗号好像不太对哦。`
- 第2次：`团子歪了歪脑袋：再想想嘛～`
- 第3次及之后：`团子表示：不对不对，再试一次！`
- 正确 `261009`：`暗号正确！团子来开门啦！`
- 点击猫独立随机气泡：`喵～`、`我是看门猫！`、`不许偷偷溜进去哦～`

不限制次数；输错轻摇输入控件，猫微跳，不要浏览器 `alert()`；输错**不强制清空输入框**；用户可编辑已有内容。

## 图层几何和已知偏差

P1原尺寸941×1672。同一设计舞台相对定位：猫 `left:246 top:450 width:405 height:248`，门 `left:285 top:676 width:351 height:413`。它们是参考像素坐标，需统一按舞台缩放，不能让背景用 cover 而猫/门另按 viewport 像素缩放。通过一个共用 `position:relative` 容器固定 `aspect-ratio:941/1672`，让图片底图填充并以百分比定位其他元素；不同比例手机可在容器外滚动，或变体调整。

P1门底目前从原图抠出，有一点白色拼接缝（可见 `P1_LAYER_ALIGNMENT_01.jpg`），**需用合理遮罩或背景色缝合精修**。CSS 可在门之后绘制一个遮挡条，但不得盖住按钮。打开时用深暖色内景背板（CSS拱形遮罩），door设 `transform-origin:left center`，动画可 `rotateY`/`scaleX` 或平移叠遮罩；不能直接把背景空洞暴露成白色空白。

## 交互/键盘

- 输入真实 `<input type="password" inputmode="numeric" pattern="[0-9]*" maxlength="6" autocomplete="off" enterkeyhint="done">`，移动端唤起数字键盘，禁使用 `type=number`（前导零与长度限制不稳定）。
- 应接收粘贴的6位数字，过滤非数字，Enter/提交按钮调用同一验证函数。
- 成功后 `input.blur()` 收起键盘，并在门动画结束后自动转 P2，避免二次点击多次触发。
- 键盘弹出时小屋插画可缩小/收起，表单滚动到安全区；用 `100dvh`、`env(safe-area-inset-bottom)`、可滚动容器，酌情 `visualViewport`；不要在键盘出现后把整张 stage 强制拉扁或让按钮跑到键盘后面。
- P1只是纪念性质轻度门槛，公开 GitHub Pages 的访问码能被源码看到；不应宣传数据私密。
